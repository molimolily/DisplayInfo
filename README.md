# DisplayInfo

接続されたモニターの EDID を読み取り、各パラメータを表示します。

| ブロック | 主な表示項目 |
| --- | --- |
| 基本 EDID | バージョン、アナログ／デジタル入力、詳細タイミング、確立タイミング I〜III、標準タイミング、ディスプレイの周波数範囲と最大ピクセルクロック |
| CTA-861 | ビデオデータブロックの VIC とネイティブ指定、詳細タイミング、YCbCr 4:4:4・4:2:2・4:2:0、色域、HDR 静的メタデータ |
| DisplayID | バージョン、各データブロックのタグと長さ、1.x の Type I および 2.x の Type VII 詳細タイミング |
